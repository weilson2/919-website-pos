# 919 Website POS source

This folder contains the Python web server, browser interface, pricing helper,
tools, tests, and Python environment. Start the existing live system with
`..\START_WEB_POS_LOCAL.cmd` so it receives the shared Desktop POS database path.

See `..\README.md` for current launch and development instructions.
See `SETUP_AND_OPERATIONS.md` and `DEPLOYMENT_CHECKLIST.md` for the detailed
operating procedures. Their generic source-checkout instructions use a local
`pos.db`; the live database in this organized workspace is instead
`..\..\Desktop POS\app\pos.db`.

Desktop application source and build definition now live in
`..\..\Desktop POS\source`. The earlier combined README is preserved under
`..\..\Desktop POS\Archive\Transfer Notes\ORIGINAL_SOURCE_README.md`.
